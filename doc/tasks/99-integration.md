# 99 — 端到端整合測試

> 對應設計：HLD §5 端到端資料流、proposal §9.5（同區網實機驗證）
> 目標：前後端串接後，於真實環境驗證完整資料流與非功能需求。
> 依賴：所有 Backend 與 Frontend 模組完成。

## 完成定義 (DoD)
- 同區網裝置（含手機/平板）可正常瀏覽即時與歷史資料。
- 長時間執行穩定、單次失敗不崩潰。

## 子任務
### 功能驗證
- [x] 啟動 Backend，等待數個取樣週期，DB 有資料累積
- [x] 啟動 Frontend，畫面每 10 秒更新即時卡片
- [x] 切換 1h / 6h / 24h / 7d，折線圖正確顯示且點數受降抽樣控制
- [x] CORS：前端（不同 origin/port）可成功呼叫 API

### 非功能驗證
- [x] 同區網其他裝置以本機 IP 存取前端與 API 成功（手機/平板 RWD 正常）
- [x] 失敗隔離：手動製造取樣/寫入失敗，服務不崩潰、後續迴圈續行
- [x] 清理：驗證超過保留天數的舊資料被刪除（可暫時調小 retention 測試）
- [x] 長時間執行（數小時）資源占用低、無記憶體洩漏徵兆
